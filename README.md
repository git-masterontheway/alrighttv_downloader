# Alright TV Downloader

A full-stack, mobile-responsive streaming web application and automated season downloader.

## Features
- **Featured Rails**: New Releases, Trending Shows, CEO Dramas, Romantic Dramas, and Binge Worthy series.
- **Dynamic Search**: Instant show lookups and season discovery.
- **Automated Season Merging**: Downloads and merges all episode stream segments into a continuous single 1080p MP4 file.
- **Cross-Platform**: Render-ready backend (Linux) with `ffmpeg-static` support and local Windows development compatibility.
- **Frontend Integration**: Compatible with standalone domains like `https://asialrighttvdownloader.free.nf/` or unified Render hosting.

## Deployment on Render
1. Connect this repository to your Render Web Service.
2. Build Command: `npm install`
3. Start Command: `node server.js`
4. Set Environment variable (optional): `PORT=3030`
